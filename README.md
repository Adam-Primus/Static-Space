# Static-Space
A Space Themed Warioware-styled pixel Game that consists of many minigames. It's main purpose is to survive and reach Earth.

<img width="700" alt="Game Page" src="https://github.com/user-attachments/assets/35f1aff4-05e9-48ad-b76e-f9bdce1f53b0" />

## Try It Out !!

https://adam-primus.itch.io/static-space


## Features
- 3 *Minigames*
- Unique *Winning* and *Losing* Scene
- 3 Lives with a Special Element representing the Lives
- A *Nonsensical Joke at the end of 3rd Minigame*
- A non-cool Player
- No sound like in outer space

## Scenes
It has total of  scenes:
- Title / Main
- Timer / Waiting
- Minigame 1
- Minigame 2
- Minigame 3
- Winner
- Loser

It also has some other screens that overlaps in the scenes above such as:
  
- Player
- Spacecraft
- Timer

## Key Configuration
- <kbd>→</kbd> Arrow Key : Move Forward
- <kbd>←</kbd> Arrow Key : Move Backward
- <kbd>↑</kbd> Arrow Key : Move Up
- <kbd>↓</kbd> Arrow key : Move down
- <kbd>Space Bar</kbd> : Jump
- Mouse Pointer : Select
